# Bitcoin Holdings para Omarchy

Plugin planejado para acompanhar quanto uma quantidade fixa de Bitcoin vale na moeda escolhida, diretamente na barra do Omarchy 4 (Quattro).

Ao clicar no valor, um painel exibirá o gráfico dessa mesma quantidade de BTC ao longo da semana, mês, ano ou cinco anos.

## Estado

Repositório iniciado para especificação e desenvolvimento posterior. Ainda não contém um plugin instalável.

## Configuração prevista

- Quantidade de BTC, informada pelo usuário e salva localmente.
- Moeda de exibição, com BRL como padrão.

O objetivo é acompanhar uma posição fixa. Não haverá compra, venda, conexão com carteira ou corretora, nem registro de transações.

## Desenvolvimento

A especificação e os critérios de aceite estão em [SPEC.md](SPEC.md) e no primeiro issue do repositório. O próximo agente deve começar validando uma fonte de dados que cubra cinco anos na moeda selecionada.
